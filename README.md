# ECO UNIVERSITARIO

Periódico digital académico de la Universidad Canadiense.

## Archivos
- `index.html`: portada pública.
- `styles.css`: diseño responsive.
- `app.js`: noticias, búsqueda y navegación.
- `admin.html`: formulario local para crear noticias.

## Importante sobre la primera versión
El panel de administración utiliza `localStorage`. Esto significa que las noticias nuevas quedan guardadas únicamente en el navegador/dispositivo donde se publican. Es excelente para una demostración escolar, pero no es todavía un sistema multiusuario en Internet.

## Publicación gratuita
Esta versión puede publicarse como sitio estático en GitHub Pages, Netlify o Vercel. Para un sistema real de redacción desde cualquier computadora, habrá que conectar el formulario a una base de datos/autenticación.

## Periodicidad
La periodicidad editorial prevista es cada 8 días. El sitio no publica automáticamente: el responsable editorial decide qué noticia se publica en cada edición.
